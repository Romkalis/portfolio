Создай fullstack web-приложение для шиномонтажа на Next.js (App Router) с современным frontend и backend.

Технологии:
- Next.js 15+
- TypeScript
- React
- Prisma ORM
- PostgreSQL
- NextAuth/Auth.js для авторизации
- React Hook Form + Zod
- Recharts или Chart.js для графиков
- Zustand или Redux Toolkit для state management
- Docker support
- ESLint + Prettier
- Component-based architecture

Главная задача:
Разработать удобную систему управления расписанием сотрудников шиномонтажа, учетом выручки, зарплат и аналитики.

Основные роли:
1. Employee (сотрудник)
2. Admin / Owner (начальник)

====================================
ФУНКЦИОНАЛ СОТРУДНИКА
====================================

- Авторизация и регистрация
- Личный кабинет
- Просмотр собственного расписания
- Возможность отмечать дни и смены, когда сотрудник может работать
- Возможность указывать:
  - дату
  - время
  - комментарий
- Просмотр:
  - подтвержденных смен
  - отклоненных смен
  - заработка за период
- Адаптивный интерфейс

====================================
ФУНКЦИОНАЛ НАЧАЛЬНИКА
====================================

Dashboard / Admin Panel:

- Просмотр всех сотрудников
- Подтверждение или отклонение смен сотрудников
- Удобный календарь смен:
  - таблица
  - week view
  - month view
- Возможность редактировать расписание вручную
- Просмотр аналитики за:
  - день
  - неделю
  - месяц
  - произвольный период

====================================
ФИНАНСЫ И АНАЛИТИКА
====================================

Создать раздел “Финансы”.

Возможности:
- Ввод общей выручки за день
- Ввод зарплаты сотрудникам
- Ввод расходов вручную

Пример расходов:
- Грузики
- Материалы
- Аренда
- Прочее

Каждый расход содержит:
- название
- сумму
- дату
- комментарий

Система должна автоматически:
- считать чистую прибыль
- считать расходы
- считать зарплаты
- считать итоговый доход за период

====================================
ГРАФИКИ И ВИЗУАЛИЗАЦИЯ
====================================

Добавить красивые графики:
- выручка по дням
- прибыль по неделям
- зимний сезон (счиать данные с 01.07 по 31.12)
- летний сезон (счиать данные с 01.01 по 01.07)
- расходы по категориям
- зарплаты сотрудников
- сравнение периодов

Использовать:
- Recharts или Chart.js
