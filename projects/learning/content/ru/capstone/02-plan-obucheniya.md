# Capstone 2: ваш план

## Кому этот урок

Курс пройден по материалам. План **закрепления на реальном CRM** и роста до уверенного junior по этому стеку.

## Что вы узнаете

- Расписание по неделям
- Мини-проекты после каждого блока
- Финальный проект

## Недели 5–6 — CRM hands-on

Читать `docs/` параллельно с кодом. Задачи по возрастанию:

### Уровень A (наблюдение)

1. Добавить поле `note` в Owner (schema + migrate + форма + list).
2. Изменить подпись статуса в UI.
3. Новый пункт в sidebar (заглушка страницы).

### Уровень B (логика)

4. Фильтр заказов по статусу через `searchParams`.
5. Экспорт CSV выполненных заказов за месяц (server action).
6. Счётчик «ожидающих» на главной dashboard.

### Уровень C (безопасность и качество)

7. Пройти чеклист `docs/SECURITY.md` и найти 1 место для улучшения (с обоснованием).
8. Написать e2e сценарий вручную (чеклист кликов) для создания заказа.

## Финальный проект (2 недели)

**Вариант 1:** форк CRM — новый модуль «Склад запчастей» (Part, StockMovement).  
**Вариант 2:** свой мини-CRM для другой ниши (стоматология, фитнес) с тем же стеком.

Критерии сдачи себе:

- [ ] Auth работает
- [ ] 3+ сущности в Prisma со связями
- [ ] CRUD через Server Actions + Zod
- [ ] `npm run build` зелёный
- [ ] README: как поднять за 10 минут

## Задания capstone

### 1. Персональный план (20 мин)

Заполните таблицу: сколько часов в неделю, дата «первая рабочая CRM локально».

### 2. Выбор финального проекта (10 мин)

Вариант 1 или 2 — один абзац обоснования.

### 3. Портфолио (30 мин)

README в GitHub: скрин CRM, стек списком, ссылка на learning site.

### 4. Самопроверка (15 мин)

Без подсказок объясните вслух: Server Action vs API route, зачем Zod, зачем middleware.

### 5. ⭐ Менторство

Попросите коллегу/друга пройти login и создать заказ — зафиксируйте 3 UX-замечания.
