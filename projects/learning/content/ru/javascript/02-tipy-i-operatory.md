# Урок 2. Типы и операторы

## Кому этот урок

Вы прошли урок 1 и умеете `const`, объекты и простые функции. Сейчас разберём **массивы** (списки заказов), **операторы** и **условия** — без них нельзя ни одна страница CRM.

## Что вы узнаете

- Массив и обход `for...of`

- Приведение типов и ловушки `==`

## 1. Массив — список однотипных вещей

```javascript
const заказы = ["Замена масла", "Диагностика", "Шиномонтаж"];
```

| Действие | Код | Результат |
|----------|-----|-----------|
| Длина | `заказы.length` | `3` |
| Первый элемент | `заказы[0]` | `"Замена масла"` |
| Последний | `заказы[заказы.length - 1]` | `"Шиномонтаж"` |
| Добавить в конец | `заказы.push("Развал")` | массив из 4 |

**Индексы с нуля:** первый элемент — `[0]`, не `[1]`.

### Массив объектов (как в CRM)

```javascript
const заказы = [
  { id: 1, title: "Замена масла", status: "PENDING", price: 3500 },
  { id: 2, title: "Диагностика", status: "COMPLETED", price: 2000 },
];
```

Доступ:

```javascript
заказы[0].title;   // Замена масла
заказы[1].status;  // COMPLETED
```

## 2. Обход массива

### for...of — читабельно для новичка

```javascript
for (const заказ of заказы) {
  console.log(заказ.title, "—", заказ.status);
}
```

### Классический for — когда нужен индекс

```javascript
for (let i = 0; i < заказы.length; i++) {
  console.log(i, заказы[i].title);
}
```

Позже вы будете чаще использовать `.map` / `.filter` (урок 3).

## 3. Числа и деньги

```javascript
const цена = 15000;
const скидка = 0.1;
const итого = цена * (1 - скидка); // 13500
```

**Важно:** в JS нет отдельного типа «деньги». В CRM суммы хранят в PostgreSQL как `Decimal`, в JS на сервере часто `Number` или строка — не складывайте деньги через `0.1 + 0.2` без округления (пока просто знайте, что бывают `13500.0000000001`).

Округление:

```javascript
Math.round(13500.6);  // 13501
Math.floor(3.9);      // 3
```

## 4. Строки

```javascript
const vin = "XTA21144012345678";
vin.length;                    // длина
vin.toUpperCase();             // верхний регистр
vin.includes("211");           // true — есть подстрока
"  +7903  ".trim();            // убрать пробелы по краям
```

Склейка:

```javascript
"Заказ #" + 5;           // Заказ #5 — число станет строкой
`Заказ #${5}`;            // то же
```

## 5. Операторы сравнения

| Оператор | Значение |
|----------|----------|
| `===` | равно (тип и значение) |
| `!==` | не равно |
| `>`, `<`, `>=`, `<=` | больше / меньше |
| `&&` | И (оба true) |
| `\|\|` | ИЛИ (хотя бы одно true) |
| `!` | НЕ |

```javascript
const status = "PENDING";

status === "COMPLETED";           // false
status === "PENDING";             // true
status === "PENDING" && price > 0; // true если цена > 0
```

### Почему не ==

```javascript
0 == false;   // true — путает
0 === false;  // false — правильно
```

**Правило курса: только `===` и `!==`.**

## 6. Условия if / else

```javascript
function badgeText(status) {
  if (status === "COMPLETED") {
    return "Выполнен";
  } else if (status === "PENDING") {
    return "В работе";
  } else {
    return "Неизвестно";
  }
}
```

### Тернарный оператор — короткое if

```javascript
const label = status === "COMPLETED" ? "Готово" : "Ждёт";
```

Читается: *если* условие *то* первое значение *иначе* второе.

---

## 7. switch — много вариантов одного поля

```javascript
function statusColor(status) {
  switch (status) {
    case "PENDING":
      return "orange";
    case "COMPLETED":
      return "green";
    default:
      return "gray";
  }
}
```

В CRM статусы заказа — типичный кейс для `switch` или объекта-маппинга.

## 8. null и undefined

```javascript
let phone;           // undefined — не задавали
const note = null; // null — явно «пусто»

if (phone === undefined) {
  console.log("Телефон не указан");
}
```

**Опасная привычка:**

```javascript
if (phone) { ... }  // сработает и на "", и на 0 — не всегда то, что нужно
```

Для новичка лучше явно: `phone === undefined || phone === null` или позже — проверка через Zod.

## 9. Объект vs массив — не путать

| | Массив | Объект |
|---|--------|--------|
| Порядок | Да, по индексу | Поля по имени |
| Синтаксис | `[1, 2, 3]` | `{ a: 1 }` |
| В CRM | Список заказов | Один заказ |

```javascript
Array.isArray(заказы);  // true
Array.isArray({});      // false
```

## Частые ошибки

| Ошибка | Пример | Исправление |
|--------|--------|-------------|
| Индекс с 1 | `arr[1]` ждут первый | `arr[0]` |
| Сравнение объектов | `obj1 === obj2` всегда false | сравнивать поля |
| `if (status = "PENDING")` | присвоение вместо сравнения | `===` |
| Пустой массив | `arr[0]` без проверки | `arr.length > 0` |
