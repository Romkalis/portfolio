# Урок 1. JavaScript с нуля

## Кому этот урок

Вы **никогда не программировали** или пробовали мало. Через 40–60 минут вы поймёте, что такое JavaScript, запустите код в консоли и напишете первые строки логики — как в CRM, только проще.

## Что вы узнаете к концу урока

- Что такое JavaScript и где он работает в нашем проекте

## 1. Что такое JavaScript простыми словами

**JavaScript (JS)** — язык, на котором пишут поведение программ:

- в браузере: кнопки, формы, фильтры;
- на сервере (Node.js): загрузка данных из базы;
- в Next.js (CRM): **и там, и там**.

Аналогия: HTML — «скелет» страницы, CSS — «внешний вид», **JS — «мозг»** (что происходит при клике, что показать в таблице).

Весь стек CRM в итоге выполняется как JavaScript. TypeScript — это JS + подсказки типов (следующие модули).

## 2. Где вы будете писать код

### Вариант А — консоль браузера (самый быстрый старт)

1. Откройте Chrome или Firefox.
2. Нажмите **F12** (или ПКМ → «Просмотреть код»).
3. Вкладка **Console**.
4. Внизу введите и нажмите Enter:

```javascript
console.log("Привет, автосервис");
```

Вы должны увидеть текст `Привет, автосервис`. **Поздравляем — вы запустили JS.**

### Вариант Б — Node.js в терминале

Если установлен Node:

```bash
node
```

Появится приглашение `>`. Туда же:

```javascript
console.log(2 + 2);
```

Выход: `Ctrl+C` два раза или `.exit`.

### Вариант В — файл (как в реальных проектах)

Создайте `test.js`:

```javascript
console.log("Заказ №1 создан");
```

Запуск:

```bash
node test.js
```

В CRM код живёт в `.ts` / `.tsx`, но **логика та же**.

## 3. Переменные — коробки с подписью

Программа хранит данные в **переменных**.

```javascript
const названиеСервиса = "Автосервис CRM";
let количествоЗаказов = 0;
```

| Ключевое слово | Можно ли менять значение позже? |
|----------------|----------------------------------|
| `const` | **Нет** (используйте по умолчанию) |
| `let` | **Да** |

```javascript
количествоЗаказов = количествоЗаказов + 1;
console.log(количествоЗаказов); // 1
```

**Не используйте `var`** в новом коде — старый стиль, путает область видимости.

### Имена переменных

- латиница, camelCase: `clientPhone`, `orderCount`
- осмысленно: `cp` — плохо, `customerPhone` — хорошо

---

## 4. Типы данных (минимум для старта)

| Тип | Пример | Зачем в CRM |
|-----|--------|-------------|
| string (строка) | `"Toyota"`, `"+7903..."` | Имена, VIN, телефон |
| number (число) | `2018`, `15000.50` | Год, сумма, пробег |
| boolean (да/нет) | `true`, `false` | Выполнено, активен |
| null | `null` | «Специально пусто» |
| undefined | не задано | Поле не заполнили |

```javascript
const марка = "Toyota";
const год = 2018;
const завершён = false;
const комментарий = null;
```

Проверка типа в runtime:

```javascript
typeof марка; // "string"
typeof год;     // "number"
```

## 5. Объект — одна «карточка» с полями

Клиент в CRM — это объект:

```javascript
const клиент = {
  id: "001",
  фамилия: "Иванов",
  имя: "Сергей",
  телефон: "+79031112233",
};
```

Чтение полей:

```javascript
console.log(клиент.фамилия);   // Иванов
console.log(клиент["телефон"]); // +79031112233
```

В реальном проекте поля на английском: `lastName`, `firstName` — так в базе и в коде.

## 6. Функция — именованный кусок логики

**Зачем:** не копировать один и тот же код, а вызывать по имени.

```javascript
function полноеИмя(фамилия, имя) {
  return фамилия + " " + имя;
}

const подпись = полноеИмя("Иванов", "Сергей");
console.log(подпись); // Иванов Сергей
```

- `function` — объявление
- `(фамилия, имя)` — **аргументы** (вход)
- `return` — **результат** (выход)

Короткая форма (часто в списках и фильтрах):

```javascript
const удвоить = (x) => x * 2;
console.log(удвоить(5)); // 10
```

В CRM: `formatMoney`, `fullName`, `carLabel` — всё функции.

---

## 7. Шаблонные строки

Удобнее склеивать текст:

```javascript
const марка = "Toyota";
const модель = "Camry";
const год = 2018;

const подпись = `${марка} ${модель} (${год})`;
// Toyota Camry (2018)
```

Обратные кавычки `` ` `` и `${переменная}`.

---

## 8. Сравнение — только ===

```javascript
const статус = "PENDING";

статус === "PENDING";  // true — правильно
статус == "PENDING";   // избегайте — странные приведения типов
```

Запомните: **`===`** для сравнения значений.

## 9. console — ваш друг на первых неделях

```javascript
console.log("отладка", клиент);
console.log("заказов:", количествоЗаказов);
```

В CRM на сервере `console.log` виден в терминале `npm run dev`, в браузере — в DevTools.

## 10. Как это связано с CRM (уже сейчас)

| В учебнике | В projects/service |
|------------|-------------------|
| `const клиент = { ... }` | Данные из PostgreSQL через Prisma |
| `function полноеИмя` | `fullName()` в `utils.ts` |
| `console.log` | Отладка при разработке |
| `===` | Сравнение статусов заказа |

Вы пока не трогаете Next.js — только **мышление на JS**.

## Частые ошибки новичков

| Ошибка | Что видите | Как правильно |
|--------|------------|---------------|
| Забыли кавычки у строки | Синтаксическая ошибка | `"текст"` |
| `const x = 1; x = 2` | Ошибка | Используйте `let` если меняете |
| Путают `=` и `===` | Логика ломается | `=` присвоить, `=== сравнить |
| Нет `return` в функции | `undefined` вместо результата | Добавить `return` |
